Spendly is a web-based expense tracking application developed to help users manage and monitor their daily
financial transactions efficiently. The project aims to provide a simple, secure, and user-friendly platform for
recording expenses, categorizing spending, and maintaining financial discipline. The application is built using
HTML, CSS, and JavaScript for the frontend, while Firebase Authentication and Cloud Firestore are used as
backend services for secure user login and real-time database storage. Users can add, edit, delete, and
organize expenses based on categories, enabling better tracking and analysis of personal spending habits.
The system follows a client-server architecture where the frontend interacts with Firebase services to store
and retrieve data in real time. Spendly emphasizes responsive design, usability, and secure data handling
while demonstrating integration of modern web technologies with cloud-based backend support. The
project also implements Firebase security rules to ensure authorized data access and privacy. Through its
interactive dashboard and real-time synchronization, Spendly offers an efficient alternative to traditional
manual expense tracking methods. The application can be further enhanced with advanced features such as
expense analytics, budget prediction, and mobile integration, making it a scalable solution for personal
financial management.
